How to share

Give an external audience a read-only view of the live plan. They do not use the site staff login. You create a labelled link in this app and send the password separately.

1. Open Admin → Sharing

Sign in as staff (Microsoft or Dev Login). In the tracker, open Admin, then Sharing. Do not send people to /login — that door is for staff only.

2. Add an audience

Use a label you will remember (for example Board pack). Set a password and how long the link should last, then create the share.

3. Send the link and the password

Copy link and send that URL. Tell them the password another way — not in the URL and not in the same message if you can avoid it.

4. What the viewer sees

They open the guest page, enter their name and that password, and see a read-only live plan. Site/Staff login will not open this view.

5. Cut access

Disable that audience (or let it expire) to cut that link. Other audiences stay on. Replace password on a row if you need to rotate one audience without touching the others.

6. If View stops working

A zip deploy can clear shares stored on disk. Recreate the audience in Admin → Sharing — not in Azure. Guest activity on this instance is a file log, not an audit archive.
