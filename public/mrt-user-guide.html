What this is

The Milestone Resourcing Tracker plans regulator cycles for dam safety: each dam × requirement type × due date. It is not a list of named engagement milestones.

Staff apply a seeded catalog of obligation types and roles, and may add or rename. Plan hours sit on Defaults (by role) and on the occurrence popup (by person). Those hours seed once: saving an occurrence keeps that plan even if Defaults change later.

Load is a heatmap of planned hours against weekly available hours. The app does not level or auto-move work.

Tabs

Product tabs sit under the page title. ← Back returns to the previous tracker tab when you jumped (for example from Gantt to a person on Inputs).

  • Gantt — cyclical timeline and resource-hours pane.
  • Obligations — every occurrence as a table.
  • Inputs — assets, types, roles, named people.
  • Definitions — applicability and ownership matrices.
  • Defaults — lead-in months and default effort hours.
  • Help — Quick reference and this User guide.

Guests see those six tabs, read-only. Staff also see Admin (sharing) and Development (changelog and notes).

Gantt

Each row is a dam × obligation type. Diamonds on the timeline are occurrences: predicted (open), scheduled (solid), completed, or not required. The working rule: drag a due, then Recalc so later dates keep that week-ending.

  • Filter by Asset, Type, and Due. Each filter has Select all / Clear all.
  • Switch grain with Weeks / Months. Zoom the timescale and the row height.
  • On screen centres today. First due jumps to the earliest filtered obligation that is still on the board (not complete).
  • Drag a diamond to move that due. Task hours on the Effort chart move with the milestone (tail-end shift; stick unchanged).
  • Flatten, Dam↔Obl, and the FY timeline sit on the chrome row above the chart. Open Legend for marker colours.

Recalc and First due

After you drag a due, later predicted dates on that row may still be on the old cycle. Press ↺ Recalc on the row. Recalc uses the next known due as the cycle origin (skipping not-required). Scheduled and completed stays. Predicted futures are replaced. Hidden predicted occurrences come back.

Recalc keeps the week-ending day you dragged — not month-end. If you move a due inside the same month, ↺ turns amber until you Recalc. Obligations has the same Recalculate action.

First due (next to On screen) scrolls to the earliest incomplete marker in the current filters.

Resource hours

The lower Gantt pane is planned load by person and week. Cells stay blank when hours are at or under weekly available capacity. Yellow is over 100%. Red is over the overrun threshold (default 125%, set on Inputs → Resource Names).

  • Hover or click a yellow/red cell to see which obligations stack that week.
  • Rebalance opens those contributing Effort charts on one week axis so you can edit hours by hand. It does not auto-level.
  • Click a name to jump to that person on Inputs. Availability and summary toggles (This milestone | Everywhere, Total | Available/over) live on the Effort chart, not only here.

Occurrence and Effort

Click a diamond (or open a row from Obligations) for the occurrence popup. Set due date, lead-in and tail, assign people to tasks, and plan hours on the Effort Gantt.

  • Task, Role, and Name stay frozen on the left; week columns scroll. Hide a meta column with ×; bring it back from Columns.
  • Toolbar groups: Unstick / Tail start / Tail end · Columns · Centre / Collapse / Availability.
  • Resource summary hours update while you drag. Weeks zoom is an inline chip (− % +).
  • Save writes hour edits. Save and Close does both. Close (and Esc) discard unsaved hour edits. The italic note under the chart reminds you that Defaults seeded this plan once.
  • Changing role keeps the name and warns with * when that person is out of the role catalog for the dropdown.
  • Reset icons restore due/tail or hours to Defaults without snapping the window to the tail.

Project Management

Enable Project Management is off by default. When it is on, the Effort chart shows status, actual hours / actual $, FAC, and VAC — and forces Hours and Costs columns on. FAC is actuals plus remaining planned from today. VAC is FAC minus budget. The heatmap still uses planned hours only.

Obligations

A table of every occurrence in the horizon. Sub-tabs: All Obligations, Ongoing (overdue and in the lead-in window now), and Upcoming (next dues inside the look-ahead you pick).

  • Filter assets and obligation types (Select all / Clear all).
  • Open a row for the same occurrence popup as the Gantt.
  • Go to Gantt centres that marker and pulses it.
  • Recalculate on a row is the same cycle rebase as Gantt ↺.

Inputs

The catalog you plan against. Four sub-tabs:

  • Assets — dams on this plan.
  • Obligation Types — regulator requirement types and their cycle (for example every n years).
  • Resource Roles — role catalogue, rates, default weekly hours.
  • Resource Names — named people, roles they hold, weekly available hours, overrun threshold. External rate shows a colour dot when it differs from the role default.

Cross-links take you to the matching Definitions matrix. Removing a dam, type, role, or person cascades so leftover assignments do not orphan.

Definitions

  • Asset × Obligation — which types apply to which dams, plus each cycle origin (the date later Recalc uses).
  • Resource × Role — who can fill which roles in the Effort dropdowns.
  • Asset × Resource Role — named owners per dam, region, or all assets, by role.

Defaults

  • Lead-in time per dam — months of lead-in before each dam × obligation due. That window is the Effort chart for a new occurrence.
  • Task+Resource Effort — default hours by role that seed a new occurrence once. After you save that occurrence, editing Defaults does not overwrite it. Reset on the occurrence restores the current Defaults if you want that.

Cross-links on Defaults go to Inputs (Assets, Obligation Types, Resource Roles).

Shared view

A guest opens a labelled link, enters their name and the share password, and sees the live plan read-only. They do not use the site Microsoft login. They cannot save. Tabs: Gantt, Obligations, Inputs, Definitions, Defaults, and Help.

Home, Feedback, Admin, and Development are hidden. If a control looks faded, it is display-only.

Staff

Create and cut guest links under Admin → Sharing. The staff how-to is Admin → Guides → How to share (HTML and PDF). Do not put the share password in Azure App Settings. Copy the link; tell the password another way.

Development → Changelog is what shipped and what is still WIP. Development → Notes is a staff-only scratchpad saved with this plan — not shown on a guest share.

Out of this version

Followups, Assumptions, non-resource / intangibles costing, and automatic leveling. The heatmap is planned hours only. Guests do not get a click-drag sandbox in this version.
