Quick reference

Use this as a map. Where a topic has more detail, More opens that section of the User guide.

What this is

  • Dam-safety obligations as regulator cycles (each dam × requirement type × due), not named project milestones. More
  • Plan hours on Defaults (roles) and on each occurrence (people). Hours seed once; later Defaults edits do not overwrite a saved plan. More
  • Overrun heatmap is planned hours: blank under capacity, yellow over 100%, red over the overrun threshold. There is no auto-leveling. More

Tabs

  • Gantt — timeline of predicted and scheduled dues. More
  • Obligations — table of occurrences, status, due, lead-in. More
  • Inputs — dams, types, people, roles, weekly hours. More
  • Definitions — which types apply to which dams, who can fill which roles. More
  • Defaults — lead-in months and role-hour templates. More
  • Help — this guide and the full User guide (in the app).
  • A shared view is read-only. Admin and Development are staff only. More

Gantt

  • Filter by asset, type, and due. Weeks or Months grain. Zoom timescale and rows. More
  • Drag a milestone diamond to move that due (and attached task hours). Then Recalc (↺) so later predicted dates keep that week-ending. Amber ↺ means this row is stale. More
  • On screen jumps to today. First due jumps to the earliest filtered incomplete occurrence. More
  • Resource-hours pane: planned load vs available hours. Click a red or yellow cell for the stack; Rebalance opens several obligations for one person. More

Occurrence and Effort

  • Click a diamond to open the occurrence: due, lead-in/tail, people, and the Effort chart. More
  • Save keeps hour edits. Close discards unsaved hour edits. More
  • Enable Project Management shows status, actuals, FAC, and VAC (hours and costs). Off by default. More

Not in this version

  • Followups, Assumptions, non-resource costing, and automatic leveling. Heatmap stays planned hours. More
