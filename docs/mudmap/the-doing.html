Five locked words

ProductA toy people can open (lives in The Thing).
TicketOne job for one chat.
BoardDurable memory. Hallway bulletin. Not the chat.
HatA role. Not a forever-agent.
TempOne agent session. Reads board → does ticket → writes back.

Sequence

  1. You — owner. Talk mostly to Front desk.
  2. Front desk — split wishes into tickets; no building.
  3. Board — what’s true (products, tickets, status).
  4. Hats — temps wear one hat per chat.
  5. Cursor workspace — files under C:\…\Cursor\ are the physical school grounds (hypothesis to design next).

Hats

Front desk

  • Listen, ask, ticketize
  • Update the board

No product code.

Builder

  • One ticket only
  • Write result to board

No running the company.

Janitor

  • Harvest leftovers onto board
  • Park or bin half-ideas

No features “as tidy-up.”

Reviewer

  • Handbook check
  • Board updated? yes/no

No quiet rebuilds.
