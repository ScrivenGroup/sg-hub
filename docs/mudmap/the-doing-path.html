Hurdles roadmap · path to efficient Doing

Doing path
28 Aug 2026

Naive vibe coding = one chat that keeps building. Fine for tiny toys. When the toy grows, the first wall is usually context. This page maps the walls in order, and beside them the school + directory pieces that clear each wall — so we know the end state and the path.

Right · Structure that clears the walls

Tickets clears 1

  • One chat = one job
  • Small enough to finish before context dies
  • Front desk splits big wishes

Handbook clears 2

  • Locked words (Product, Ticket, Board, Hat, Temp)
  • Don’t contradict locked choices
  • Temps must read before building

Board / memory palace clears 3

  • What’s true lives in files, not chat brains
  • Job not done until board updated
  • Ugly table > clever memory

Hats clears 4

  • Front desk · Builder · Janitor · Reviewer
  • Allowed / forbidden per hat
  • Child workers = errands inside one ticket

Directory campus clears 5

  • Doing home = board + tickets + doing handbook
  • Thing folders = each product world (e.g. scrivengroup)
  • Experiments stay labelled, not mixed into the board
